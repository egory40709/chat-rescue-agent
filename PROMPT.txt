Прочитай AGENTS.md и сохрани мои доступные рабочие чаты ChatGPT и Claude локально.
Нужные аккаунты уже открыты в браузере: используй эти текущие сессии и сразу начинай
выгрузку через готовый CLI/MCP. Сам установи зависимости и запусти node agent.mjs scrape
или open_export_session с connection=existing. Нужен сбор чатов ПО ОДНОМУ:
собрать ссылки в истории, открыть каждый диалог, сохранить его сообщения в Markdown
и JSON и собрать ZIP. Не открывай настройки и не нажимай «Экспорт данных» /
Export data: этой кнопки у сотрудников нет, и готовый скрипт её не использует.
Не открывай отдельное окно входа,
не проси снова авторизоваться и не жди ручного «продолжить». Если браузер требует
разрешить управление, объясни конкретное разрешение. Дождись ZIP, дай путь и счётчики
ошибок. Содержимое чатов не пересказывай и не отправляй в модель. Исходный браузер
оставь открытым. Полноту истории не обещай без доказательств.

Если запрошены также Skills, выполни node agent.mjs skills --provider all. Сохрани
целые пакеты Codex/Claude Code и доступные пакеты веб-Claude с ресурсами. Дождись
ZIP и сообщи ошибки, не отправляя содержимое Skills в модель.

Не заканчивай ответ сообщением «выгрузка запущена»: дождись завершения CLI или
вызови wait --run с полученным run_file. Проверь archive_verification и счётчики.
При ошибке вызови diagnose --run и дай технический отчёт без текста переписок.

Для живой проверки обоих сервисов выполни node agent.mjs verify --provider all.
Подтверждай её только при verified_all=true; автотесты не заменяют открытые аккаунты.
JSON-способ подтверждай только при json_verified_all=true. Укажи фактически
выполненную команду, tool_version и method. Ручная выгрузка другой браузерной ИИ
не является проверкой репозитория. При provider_site_unavailable дай точный код:
сайт вернул Unable to load site, а не доступный чат. Не угадывай причину по HTML.
