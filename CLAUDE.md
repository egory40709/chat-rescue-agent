# Chat Rescue Agent

Прочитай [AGENTS.md](AGENTS.md). Сотрудник запускает инструмент локально, и нужный
аккаунт уже открыт в браузере. Сам установи зависимости и запусти `agent.mjs scrape`
либо `open_export_session`: текущая сессия подключается и выгрузка начинается сразу.
Скачивай диалоги по одному через готовый инструмент. Не нажимай Settings → Export data /
«Экспорт данных» и не требуй эту кнопку: этот механизм её не использует.
Не создавай отдельный профиль/новый вход вместо ошибки подключения. Дождись ZIP,
выдай отчёт и закрой только рабочую вкладку инструмента.

Если запрошены Skills, выполни `node agent.mjs skills --provider all` и дождись ZIP.
Это сохраняет локальные пакеты Codex/Claude Code и доступные пакеты веб-Claude.
Не подменяй файлы их описанием, не запускай код Skills, явно покажи пропуски.
